What it does

A small, focused desktop app.

01

Backup and export

Copy messages from any IMAP or POP3 account to Mbox, Maildir or a Thunderbird-compatible local folder.

02

Migrate between providers

Move mailboxes between Gmail, Outlook/Microsoft 365, Yahoo Mail and other providers, with date filters and resumable runs.

03

25 maintenance tools

Audit, clean up and diagnose accounts, with localized logs and a graphical interface instead of a command line.
